## 摘要
本页为 **SF32LB57-MOD-WD** 模组（SF32LB57-DevKit-LCD 开发板所用 LCC72 邮票孔模组）的原理图与 BOM 结构化提取。模组搭载 **SF32LB57X** 3.3V 供电系列（QFN80 封装），集成 SF32LB57 MCU + 外置/内置 QSPI-NOR Flash + 可选 PSRAM + AIC8800D40LS-N Wi-Fi/BT Combo + 晶体。模组原理图 3 页（P1 MCU/存储/时钟/音频、P2 AIC8800/RF、P3 LCC 管脚），BOM 含 **N16R8** 与 **R16N16** 两变体——**共用同一兼容 PCB，仅靠焊接的 BOM 区分型号**。数据据 EDA 矢量文本/坐标与 BOM xlsx 核对，禁止编造。

> 模组与底板关系：MOD-WD 贴装于 [[SF32LB57-DevKit-LCD_SCH_V1_1]] 底板；底板电路见该页。

## 二、关键电路提取（依据模组原理图 EDA 矢量文本/坐标）

### 2.1 模组封装与结构
- 封装：**LCC72**（72 针 LCC/邮票孔，板名 SF32LB57-MOD-WD_LCC72）。
- 屏蔽罩：U1 = SF32LB57-MOD-WF（屏蔽盖），U7 = SHIELD_SF32LB57-MOD-WF。
- 原注：**5 个 GPIO 未引到模组管脚上**（72 针之外未引出）。

### 2.2 MCU（SF32LB57，QFN80）
- 型号（按变体）：**N16R8 → SF32LB57EYBBN6**；**R16N16 → SF32LB57GYD7N6**（均为 QFN-80，3.3V 系列）。
- 内部电源：BUCK（BUCK_LX1 / BUCK_FB80 → VDD_VOUT1 / VDD_VOUT2）、VDD_RTC(75)、VDD18_VOUT(7)、VDDIOSB(6)、PVDD(3)、VBATS(5)、VDD33_VOUT1(79)、VCC(77)、AVDD33(77)、AVDD_BRF(41)、AVDD33_AUD(22)、VDDIOA(4)、ANT/BT_ANT(42)、EPAD(81)。
- 可用外设矩阵（原注）：I2C×4、SPI×2、UART×3、CAN×2、GPTIM×2、LPTIM×2、ATIM×1、PWM×1、I2S×2、PDM×2、SDIO×2、GPADC×12、WKUP×10、USB×1；所有 GPIO 可分配至 I2C/SPI/UART/CAN/PDM/PTA-BT/xTIM/PWM/I2S/PTM/LCDC/DCMI。

### 2.3 外置存储（N16R8 焊接，R16N16 DNP）
- **U2 PY25Q128HA-WXH-IR**（PUYA，128Mbit = **16MB**，WSON-8）——仅 **N16R8** 焊接；**R16N16 的 U2 整行缺失（焊盘不焊接/DNP）**。
- 接口：MPI3（PA_12 MPI3_CS、PA_13–PA_17 MPI3_D1–D0/CLK/D3）。
- 启动配置 **MEM_CFG0 / MEM_CFG1** strapping：L L = SPI Nor Flash；L H = SPI Nand Flash；H L = SD Nand Flash；H H = eMMC。

### 2.4 复位
- 复位 RC：R6 / R7（7.5kΩ）+ C19（1.5nF）；PA_34 = LONGPRESS_RST / WKUP1 / PWRKEY。

### 2.5 时钟/晶振
- **Y2 CN4048M000885C822000**（48MHz，JWT）——MCU RF 时钟，接 XTAL48M_XI/XO(44/43)。
- **X1 SX20Y040000BA1T017**（40MHz，TKD）——AIC8800 主时钟；负载电容 C49/C43 = 15pF。

### 2.6 无线（AIC8800D40LS-N，U5，QFN-36）
- SDIO：SDIO_D0–D3 / SDIO_CLK / SDIO_CMD → MCU **PA_00–PA_05 + PA_45–PA_50**（WiFi_SD2 接口）；SDIO 1bit 模式时 D2/D3 悬空（NC）。
- 控制/状态：WF_UART_TX/RX、HST_WAK_WF、WF_WAK_HST、WF_PWRKEY、2.4G_RFSW（PA_57 = WF_WK_HOST 唤醒主机）。
- 天线：模组上 **JP1（U.FL-R-SMT-1(80)，HRS 广濑）**；ANT / BT_ANT。
- RF 前端：**U6 WS7872DE-6/TR**（WILLSEMI，DFN-6，RF 开关：RF1/RF2，Mode VC）+ **L6 BLM15AG102SN1D**（磁珠）+ **FL1 FLT18D24254959D-3288A**（2.4G 滤波器）；替换料 SLFD18-5R950G-07T。
- 原注：**蓝牙 + 5G WiFi 可同时工作**；**蓝牙 + 2.4G WiFi 为硬切换、不能同时工作，需开机配置为 1**。

### 2.7 音频
- DAC：AU_DAC1P_OUT(21) / AU_DAC1N_OUT(20)（→ 底板 NS4150B）。
- MIC：MIC_ADC_IN、MIC_BIAS（PA_56 MICBIAS）、ADC1P(PA_55)/ADC1N；AVDD33_AUD(22)、AUD_VREF(23)、GPADC_VREF(63)。

### 2.8 电源
- 模组内部 PMU/BUCK 实现电源管理（**BOM 无独立 PMIC/LDO**）；外部供 VSYS / VDD33_VOUT / VCC / VBATS。
- 退耦/滤波：L4/L5（4.7µH，cjiang）、L6（磁珠）、多颗陶瓷电容（4.7µF/2.2µF/1µF/100nF/15pF 等）+ 磁珠 BLM15AG102SN1D。

### 2.9 模组引脚（LCC72，据 P3）
- 引出全部 **PA00–PA57**（58 个 MCU GPIO）+ VBATS、VDD_3V3、WF_3V3、DAC1P/DAC1N、MICBIAS、WF_UART_TXD/RXD、IOEX 各信号、ANT、GND×多、ANT 等共 72 针。
- 原注：5 个 GPIO 未引到模组针脚（72 针之外）。

## 四、物料清单要点（依据 BOM，N16R8 vs R16N16）
> **核心结论：两变体共用同一兼容 PCB，仅靠焊接的 BOM 区分型号。**

### 4.1 差异点（仅 3 处实质不同）
| 差异 | N16R8（BOM A） | R16N16（BOM B，内部 N16R16） | 性质 |
|---|---|---|---|
| ❶ 外置 NOR Flash **U2** | 有：`PY25Q128HA-WXH-IR`（16MB，PUYA，WSON-8），Qty 1 | **整行缺失**（焊盘在兼容 PCB 上不焊接/DNP） | 型号区分关键件 |
| ❷ MCU **U3** 料号 | `SF32LB57EYBBN6`（QFN-80） | `SF32LB57GYD7N6`（QFN-80） | 型号区分关键件（内部存储配置不同） |
| ❸ 0Ω 电阻位号 | 6×0Ω 含 **R13**（R13,R18,R19,R21,R23,R24） | 6×0Ω 改为 **R12**（R12,R18,R19,R21,R23,R24） | 数量/值/厂商全同，仅 1 个位号 R13↔R12（疑为 PCB 版本/配置跳线调整） |

### 4.2 两型号区别含义（据料号与命名推断）
| 型号 | 外置 NOR Flash | MCU 料号 | 推断含义 |
|---|---|---|---|
| **N16R8** | ✅ `PY25Q128HA`=16MB（外置 U2） | `SF32LB57EYBBN6` | **N16 = 16MB NOR（外置）；R8 = 8MB PSRAM（MCU 内置）** |
| **R16N16**（内部 N16R16） | ❌ 无 U2（焊盘 DNP） | `SF32LB57GYD7N6` | **N16 = 16MB NOR（MCU 内置）；R16 = 16MB PSRAM（MCU 内置）** |

- 命名解读：`N16R8` = Nor 16MB + RAM 8MB；`N16R16` = Nor 16MB + RAM 16MB。
- 两型号 **NOR 总量均为 16MB**，差异在 **PSRAM（RAM）容量 8MB vs 16MB**，且实现方式不同：N16R8 用「外置 NOR + 低集成 MCU(EYBBN6, 内置8MB PSRAM)」；R16N16 用「高集成 MCU(GYD7N6, 内置 16MB NOR+16MB PSRAM)」，故无需外置 Flash（U2 DNP）。
- ⚠️ MCU 内部具体存储映射以 SiFli SF32LB57 数据手册为准；上表为基于 BOM 料号与命名的一致性推断。

### 4.3 关键共用件（两型号完全相同，均焊接）
- MCU 平台同族：SF32LB57（仅后缀内存配置不同，封装均为 QFN-80）
- Wi-Fi/BT：`AIC8800D40LS-N`（U5，QFN-36）
- RF 开关：`WS7872DE-6/TR`（U6，WILLSEMI，DFN-6）
- 晶体：`X1` 40MHz（TKD SX20Y040000BA1T017）、`Y2` 48MHz（JWT CN4048M000885C822000）
- 天线座：`JP1` U.FL（HRS 广濑）
- 全部阻容/电感/磁珠/滤波器/0Ω电阻：同一清单（仅 0Ω 一处位号 R13↔R12 微调）

### 4.4 元件总表（BOM 实际行）
- N16R8：bom模板 实际 23 行（No.1–24，No.24 数量 0 空行），元件数量小计 54 pcs。
- R16N16：bom模板 实际 22 行（No.1–23，No.23 数量 0 空行），元件数量小计 53 pcs（少 1 即缺 NOR Flash）。
- Field汇总 标注 Total Quantity = 74（两文件文本含时间戳完全相同，疑为模板占位/未刷新，已如实标注）。
- BOM **无显式 DNP/NC 文字标记**；R16N16 通过「直接删除 U2 行」实现该焊盘不焊接，即 PCB 兼容 + 焊接区分型号的体现。

## 六、待核实问题
1. **U6 WS7872DE 功能**：BOM 未注明，据原理图（RF1/RF2，Mode VC，配 FL1 2.4G 滤波 + L6 磁珠）推断为 2.4G/5G 天线切换 RF 开关，待与规格书核对。
2. **N16R8/R16N16 存储推断**：基于 BOM 料号与命名（N16R8 = 16MB NOR 外置 + 8MB PSRAM；R16N16 = 16MB NOR 内置 + 16MB PSRAM）为一致性推断，MCU 内部存储映射以 datasheet 为准。
3. **R13↔R12 位号差异**：两 BOM 仅 1 个 0Ω 电阻位号不同，疑为 PCB 版本或配置跳线调整，具体作用待核实。
4. **底板 BOM 缺失**：开发板底板独立 BOM 未提供（见底板图纸页）。
