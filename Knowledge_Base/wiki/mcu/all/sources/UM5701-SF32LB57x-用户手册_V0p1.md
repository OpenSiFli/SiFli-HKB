## 芯片核心规格（与 DS5702/DS5701 交叉确认，UM 补充寄存器细节）
- 内核：双 Arm Cortex-M33 STAR-MC1 @240MHz（HPSYS 双性能核）/ @24MHz（LPSYS），1968 CoreMark；单精度 FPU、MPU；功耗效率 23µA/MHz @3.8V
- SRAM 592KB（HPSYS 512KB + LPSYS 80KB，全部 Retention）
- 图形：2D/2.5D **ePicasso 3.0**（最大 2048×2048）；**eZip 3.0**（无损 eZip/eZip-A；有损 JPEG/MJPEG）
- 显示：LCDC1（8080 / SPI·Dual·Quad-SPI / DPI(RGB) / JDI / 8-16b EPD）；**DCMI** 摄像头接口（DVP / SPI 系列）
- 无线：双模蓝牙 6.3（BLE Audio / LE LR）
- 音频：1×24-bit DAC；2×24-bit ADC；**Audprc** 音频处理 + **Audcodec** 编解码；Micbias LDO
- 存储：SiP NOR-Flash ≤104MHz(DTR)、SiP OPI-PSRAM ≤156MHz(DDR)；**3× MPI（MPI1/MPI2/MPI3）**；**2× SD/SDIO（SDMMC1/SDMMC2，SD3.0/SDIO3.0/eMMC）**
- 连接：USART1–4、I2C1–4、SPI1–2、CAN1–2、USB2.0 FS、2×I2S、2×PDM
- 模拟：12-bit SAR GPADC（12 通道）；**TSEN 片上温度传感器**
- 定时器：2×16b GPTIM（GPTIM1/2）、2×32b BTIM（BTIM1/2）、2×32b ATIM（ATIM1/2）、2×24b LPTIM、1×PWM、1×RTC、2×24b WDT（含 IWDT）、1×IWDT
- DMA：GPDMA（DMAC1）+ DMAC2
- 安全：AES / HASH / CRC / **TRNG** / **efusec**（eFuse 控制器）
- 其它：PTM（外设任务矩阵）、DSP 加速器、CORDIC

## 双系列电源架构（UM §3 补充，比 DS 更细）
### 电池系列 SF32LB57x（§3.1，印刷 p27–32）
- 主电 **VCC**(4V 典型) 经内部 LDO 产生 **VSYS**(3.3V) → 下游 BUCK → BUCK_FB(1.25V) → VDD_VOUT1(1.1V HPSYS)/VDD_VOUT2(0.9V LPSYS)/VDD_RET(0.7V)
- 对外输出：**VDD33_VOUT1**(3.3V LDO2，默认关，BOOTROM 自启) / **VDD33_VOUT2**(3.3V LDO3，默认关)；**VDD18_VOUT**(1.8V，供合封 PSRAM)
- **AVDD_BRF 接 VSYS**（非 3.3V）
- 充电：**VBUS** 充电输入(5V) / **VBAT** 充电输出接电池；外部充电方案时 VBAT(VBATS for QFN80) 仅测电压
- **无独立 VDDIOA 外部引脚**（QFN68 由 VSYS 内部供 IO；QFN80/BGA112 由 VDDIOA 外部供，1.8/2.5/3.3V）
- SIP：QFN68 合封 PSRAM 由 VDD18_VOUT、Flash 由 VDD33_VOUT1 内部供；QFN80/BGA112 另有 VDDIOSA/VDDIOSB 供 SIP IO
### 3.3V 系列 SF32LB57X（§3.2，印刷 p31–32）
- 主电 **PVDD**（UM 正文写「支持 1.8V 至 3.3V」；**与 DS5702 Table 4-1 的 2.97~3.63V 冲突，已按 DS 为准**）→ 下游 LDO/BUCK 同架构
- **VDDIOA** 外部供 GPIO（1.8/2.5/3.3V）；**VBATS** 电池电压检测（无需求可不接）
- AVDD_BRF / AVDD33 / AVDD33_AUD 接 3.3V
- **BUCK 不可旁路**（BUCK_FB 1.25V，启动/唤醒自动开启，hibernate 自动关闭）
- **Hibernate 合封存储供电控制**：为防 hibernate 漏电，外部供电的合封存储应由 **PA21** 作电源开关使能（hibernate 时 PA21 高阻、外部下拉关断；唤醒后 PA21 自动高电平开启）。⚠️ 但 **PA21 在 QFN68 未引出**（见 §5/Table 5-1），故 QFN68 版本须改用其它可控 GPIO（如 **PA11 / MPI2_VDD_EN / SD_VDD_EN，默认 PU**，与 52 家族电池版同法）

## GPIO 与 IO 特性（UM §5，印刷 p57–96）
- **大核域 GPIO：PA00–PA57，最多 58 个**；+ 13 个 SA IO（MPI1 合封 PSRAM）+ 13 个 SB IO（MPI2 合封 PSRAM/Flash）= SIP IO
- **QFN68 未引出 PA21、PA45–PA54、PA57（共 12 个）→ QFN68 标称 46 GPIO（UM Table 5-1 与 pinmux 表一致）；DS5702/DS5701 Table 5-3 标 47，已按 DS 为准 = 47**
- **QFN80 / BGA112 全 58 GPIO**（+6 GPO MPI IO）
- PA 引出由**封装**决定，**不由供电系列决定**——3.3V 与电池两系列同封装 GPIO 数相同
- PA24–PA27 支持**低功耗 IO**（低功耗模式下仍可输出）
- IO 结构：DS(DS1,DS0 驱动强度 0~3 递增)、IE 输入使能、PE/PS 上下拉（PE=1,PS=0 下拉 / PE=1,PS=1 上拉；阻值约 10k~40kΩ）
- 默认映射：除 **PA43/PA44 默认 SWD**（FSEL=1），其余默认 GPIO（FSEL=0）；**PA18/PA19 在 BOOTMODE1 被 BOOTROM 配为 USART1_RXD/TXD**
- 唤醒 PIN：PMUC WER 支持 PA33–PA42、PA24–PA27、PA34 等作唤醒源（§3.4）

## 复位与低功耗（UM §2 / §4，印刷 p7–14 / p49–56）
- **四类复位源**：板级（POR 上电 / BOR 欠压 / PWRKEY 电源键）、看门狗、软件、唤醒复位
- **PWRKEY 复位**：**PA34 持续高电平超过 10 秒**触发，复位除 RTC 与 IWDT 外的所有模块；标志 PMUC WSR_PWRKEY，可 WCR_PWRKEY 清除；持续时间由 **PWRKEY_CNT** 配置
- **关闭 PWRKEY 复位**：PMUC **WER[30] PWRKEY = 1**（reset）使能；设 **0** 可关闭 PA34 长高重启整芯片（PA34 即可当普通 GPIO 无时长限制使用）——详见 [[DR_PA34_PowerKey_GPIO]]
- 低功耗模式：Active / Sleep / Deepsleep / Standby / Hibernate；Hibernate 下 VDD_RTC 保持、BUCK 关闭；调试器在 hibernate 行为见 §4.2.6

## 待核实问题
1. **PVDD 电压范围冲突已按 DS 闭环**：UM §3.2 正文写「PVDD 支持 1.8V 至 3.3V」，而 DS5702 Table 4-1 推荐工作条件为 2.97~3.63V、绝对最大 3.63V。按用户判定 **以 DS 为准 = 2.97~3.63V**，UM 该表述不作数。
2. **QFN68 GPIO 数已按 DS 闭环**：DS5702/DS5701 Table 5-3 标 QFN68 = 47；UM Table 5-1 与 pinmux 表显示 12 引脚未引出（PA21+PA45–PA54+PA57），与 DS 的 47 偏差，按用户判定 **以 DS 为准 = 47**。
3. ✅ **PA21 在 QFN68 未引出（已确认正确）**：UM §3.1/§3.2 称由 PA21 控制外部电源开关；PA21 在 QFN68 未引出（UM Table 5-1），故 QFN68 须用 PA11(MPI2_VDD_EN/SD_VDD_EN, 默认 PU) 替代；QFN80/BGA112 两系列 PA21 可用。此为封装依赖，非系列依赖（修正「PA21 仅 3.3V 有」的旧口径，该口径原指 52 家族）。
4. **电池系列 QFN80/BGA112 封装**：UM §3 确认 57xY(80)/57xV(112) 封装与电源管脚存在，且 DS5701 第 5 章已完整给出其管脚/封装/最小系统，系列支持该两种封装；仅 DS5701 Table 6-1 订购信息暂未列其料号（规格书订购表待补全，非芯片能力缺陷）。
5. **功耗参数**：DS V0.2 的 Table 4-5/4-6 曾全 TBD；**V0.2.2（2026-09-24）已补充实测**（处理器/蓝牙功耗，详见 [[SF32LB57_Peripheral_Power]] §8），低功耗预算可初步核算（UM 仍无数值，草稿量产前须复核）。
6. **PCB/EMC/ESD/最小系统参考原理图/BOOT 外部 strapping**：UM 为寄存器级手册，不含上述硬件设计内容；仍待补 SiFli 硬件设计指南（HDG）与参考设计（RF 设计）。
